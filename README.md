# 方寸 · 数独

一页米白纸，一支墨绿笔。原生 TypeScript + DOM/CSS 的完整中文 9×9 数独，桌面键盘与手机触摸均可游玩，无后端、账号或在线出题依赖。

## 仓库与在线试玩

- GitHub：https://github.com/Raingor/sudoku
- GitHub Pages：https://raingor.github.io/sudoku/ （19角色版已上线，线上48项人物检查和50项完整玩法回归通过；138项单测及严格构建通过，手机首屏键盘布局已复核）
- main 推送自动执行题库及规则测试、类型检查、构建和 Pages 发布。

## 启动

使用 **Node.js 24**（验收 v24.18.0，npm 11.16.0）。

```sh
npm ci
npm run dev                 # http://localhost:5180
npm test                    # Vitest，138 项（含35项角色单测）
npm run build               # 严格 tsc --noEmit，然后 Vite 8 构建
npm run preview             # http://localhost:4180
npm run test:browser         # 独立 Chrome，对开发服务运行 50 项验收
GAME_URL=http://localhost:4180 npm run test:browser
```

`dev` 固定 5180，`preview` 固定 4180，均 `strictPort: true`。占用时明确失败，不自动漂移，不终止其他服务。5175 属于其他服务，不使用。浏览器脚本使用 Playwright 的 `channel: 'chrome'`，需要本机安装 Google Chrome，不操作已登录的用户会话。

`base: './'`，可部署到静态站点子路径。项目独立 lockfile，无兄弟目录运行时依赖。页面加载完成后的游戏逻辑不需网络；本项目**没有 Service Worker 离线安装缓存**，不承诺断网后首次打开网址。

## 玩法

- 每行、每列、每个 3×3 宫都要恰好包含 1–9，完整合法才胜利。
- 深色数字是题目固定格，不可修改；墨绿数字是自己的答案。
- 点击格子再按数字键盘，或使用实体键盘 1–9。重复填写相同答案不产生多余撤销。
- **笔记**记录候选值，同一数字再按一次移除。候选不会自动消除，也不计作答案。填写答案会清空本格笔记，不改动其他格。
- **擦除**清空所选格答案或笔记；**撤销**恢复最近一次编辑的答案与笔记，最多保存 200 次。
- 同行、同列或同宫重复时同时标记冲突参与格，带 `!` 与可访问说明。没有冲突不代表答案一定正确；不提供答案校对或提示求解。
- **重新开始**保留同题，清空用时/答案/笔记/撤销；**换一道题**生成同档题库合法变体；切难度、新题和重开都需确认，可按 Escape 取消。
- 完成后显示用时和本档最佳，锁定编辑，支持欣赏棋盘或再解一道。

### 键盘与无障碍

方向键选择格子（边缘不跨行）；Home / End 到本行首尾。`N` 切换笔记，`Delete` / `Backspace` / `0` 擦除，`Ctrl/⌘ + Z` 撤销。快捷键仅棋盘格聚焦时生效，不接管页面或弹窗输入。棋盘采用网格/行/格语义、单格 roving tab stop；固定格、候选、冲突和选择都有可访问状态。弹窗限制焦点，Escape 关闭并恢复触发位置。支持 `prefers-reduced-motion`，完成判定不依赖动画。

计时从新局显示时开始；页面隐藏、规则/确认弹窗打开、完成后暂停。续局只恢复已累计用时，不计离线时间。计时和状态同步没有动画异步锁。

## 原创题库与难度口径

`src/puzzles.ts` 有 **6 道原创基础题，每档 2 道，均附完整答案**。没有复制公开网站或第三方商业题库，也未引入外部题目数据。

题目由本仓库 `scripts/generate-puzzles.mjs` 离线算法自建，可复现：

```sh
node scripts/generate-puzzles.mjs
```

- 固定种子 `20261120`，从标准合法完成盘构造，使用数字和合法行列排列。
- 对有限的 81 个位置做一次洗牌遍历，尝试移除给定值，只有回溯确认唯一解才保留移除。最多尝试 81 次/题，不无限重试。
- 三档是**离线构造策略的题库分组**：入门使用较密线索配置（目标 43），进阶更少（目标 34），挑战使用稀疏配置（目标 25）。空格数量不能严格评估人类推理难度，未宣称经过逻辑技巧评级器校准，个人体感可能交叉。
- 运行时只从所选组取一题，应用数字置换、组内行/列置换、整组三行/三列置换、转置，题面与答案同步变换。运行时不挖题、不回溯出题、不请求服务器。有限题库的变体有可能重复，不承诺每题从未出现。
- `tests/solver.ts` 是**独立于产品规则和离线生成脚本**的位掩码回溯计数器，发现第 2 解即停止。单测逐题检查唯一解/题解一致，并对每题 5 个固定种子的合法变换再次检查，另测转置与无解/多解。

## 存档

独立 key：`puzzle-sudoku-v1`，数据 `version: 1`。

- `best`：入门/进阶/挑战各自的最佳毫秒数，`null` 表示未完成过。
- `current`：题面、答案、答案填写、笔记、最多 200 次撤销快照、累计毫秒、选择格、笔记模式。
- 有版本、字段、长度、数值范围、固定格、答案合法性与笔记一致性校验；非法当前局面丢弃，合法纪录保留。损坏 JSON 或不支持版本安全重置。
- 读取、写入、访问 localStorage 的异常均捕获；禁用存储或配额不足时继续以内存游玩，显示不持久化提示。
- 每次操作及每秒保存；`pagehide` 保存，隐藏期间暂停。纪录仅存当前浏览器，无云同步、防篡改或跨设备承诺。清理站点数据会清除存档。

## 模块与验证

- `src/engine.ts`：不可变纯规则、冲突与完成判断、编辑/笔记/擦除/撤销，不接触 DOM、存储或定时器。
- `src/puzzles.ts`：原创题库、随机源可注入的合法变换。
- `src/clock.ts`：可注入时间源的独立计时与格式化。
- `src/storage.ts`：版本化存档校验与异常降级。
- `src/main.ts` / `src/style.css`：纸面界面、输入、焦点、弹窗和生命周期。
- `tests/`：138 项单测，覆盖唯一解、变换、固定格、行列宫冲突、编辑链、完整合法才胜利、存储异常和计时，以及35项人物列表/独立选择存储测试。
- `scripts/smoke.mjs`：使用保存的真实数据格式构造可复现夹具，以真实 UI 完成最后一个空格，无产品作弊 globals，也不动态导入 `/src`，可用于生产构建。
